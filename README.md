# openHAB Modbus Ext

Экспериментальный Modbus binding для openHAB с моделью **Endpoint → Poller → Channels**.

Цель проекта — сохранить совместимость с возможностями стандартного Modbus Data Thing, но убрать необходимость создавать отдельный Data Thing для каждой точки. Конфигурация адреса, типа значения, преобразований и записи переносится на уровень канала Poller.

## Основные требования

- использовать Modbus transport из openHAB Core, не реализовывать TCP/RTU стек заново;
- один запрос Poller должен обслуживать множество каналов;
- сохранить семантику стандартного Modbus Data Thing;
- поддержать чтение и запись;
- сохранить transformations;
- сохранить адресацию BIT/INT8 через `X.Y`;
- сохранить cache/refresh и безопасную запись отдельного бита holding-регистра;
- покрыть совместимость тестами.

## Поддерживаемые ValueType

Планируется полная совместимость с типами стандартного binding:

`bit`, `int8`, `uint8`, `int16`, `uint16`, `int32`, `uint32`, `float32`, `int64`, `uint64` и соответствующие `*_swap`, поддерживаемые openHAB Core.

Проект находится на ранней стадии проектирования.
